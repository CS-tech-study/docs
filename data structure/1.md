노드에 다음 노드의 참조값을 넣어 연결하는 구조
참조값을 통해 다음 노드로 이동할 수 있으므로 노드가 메모리의 연속적인 곳에 위치할 필요 X

일반 배열과 비교했을 때 연결 리스트는 중간 삽입, 삭제 시 뒤의 내용을 전부 한 칸씩 밀 필요가 없으므로 (참조값만 수정해주면 됨) 중간 삽입, 삭제에 유리, 그러나 원하는 노드의 탐색이 head부터 시작해서 참조값을 타고 들어가야 하므로 일반 배열보다 느림

## 동적 배열

메모리 상에 원소들이 **연속적으로 배치**된 구조이기 때문에 탐색이 O(1) (임의 접근 가능)
다만, 일반 배열은 사이즈가 고정되는 것과 달리 달리 사이즈가 고정되지 않고 계속 넣을 수 있음
>처음에 메모리를 할당하고 용량이 초과되면 더 큰 메모리 공간으로 이사하고 기존 값을 전부 복사하는 형식으로 구현

c++ vector, java ArrayList

## 이진 탐색 트리

left 혹은 right child를 가지는 구조
특정 방향으로만 child가 계속 추가된다면 일직선 형태로 되어 
트리 구조의 이점인 O(logN)의 탐색이 안될 수 있다
이를 해결하기 위한 구조가 균형 이진 탐색 트리로 대표적인 예가 AVL 트리, Red-Black 트리

C++ map, set은 내부적으로 **(Key, Value) 쌍을 정렬된 상태로 유지하는 균형 이진 탐색 트리** 사용
루트 기준으로 본인보다 작은 값은 왼쪽 자식에, 본인보다 큰 값은 오른쪽 자식에 들어가도록 하고
왼쪽 자식 -> 루트 -> 오른쪽 자식 순으로 순회하는 **중위 순회 사용 시 오름차순 정렬 효과**

반면 unordered_map, unordered_set은 해시 테이블 기반이기 때문에 삽입, 삭제가 O(1)으로 더 빠르지만 
위와 같이 트리 구조가 아니므로 정렬 효과 X(이름이 unordered인 이유)

C++ map, set, Java TreeMap, TreeSet
C++ unordered_map, unordered_set, Java HashMap, HashSet

문자열의 첫 문자부터 차례대로 해당 문자의 노드가 존재하지 않는다면 추가 해주고 이동, 노드가 이미 존재한다면 해당 노드로 이동
